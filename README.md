# Vending Machine Management System (VMMS)

A full-stack management tool for monitoring vending machine stock and processing refills.

## 🛠 Tech Stack
- **Backend:** PHP (LAMP Stack)
- **Database:** MySQL (Database name: `bdbb4`)
- **Frontend:** JavaScript, HTML5, CSS3

## 🚀 Key Features
- **Automated Inventory Tracking:** Calculates machine capacity percentages dynamically.
- **Smart Validation:** Prevents refills on "Out of Service" machines and validates quantity limits using JavaScript and PHP.
- **Relational Design:** Uses Foreign Keys and SQL Constraints to ensure data integrity.

## 📦 Installation
1. Import `vending_machine.sql` into a MySQL database named `bdbb4`.
2. Place files in your server's root directory (e.g., `htdocs`).
3. Open `index.html` via your local server.
